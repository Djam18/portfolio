approach: "Pipeline CI/CD avec GitHub Actions : lint → tests → build → push image Docker → déploiement sur VPS Linux via SSH. Nginx comme reverse proxy. Monitoring basique avec UptimeRobot."
expectedOutcome: "Un template de pipeline réutilisable, documenté et open-source, applicable à n'importe quelle app Node.js ou Laravel."
